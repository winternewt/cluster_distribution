Detecting clusters in Poisson noise — live demo

Each frame draws N uniform points in a disk (pure noise / complete spatial randomness), runs DBSCAN, and measures every detected cluster's density ratio. Left: the field with detected clusters outlined. Middle: the rescaled density ratio R·εα(ε) histogram converging to the predicted master curve (shifted inverse-gamma master, integer shape 10 = min_samples — the same curve at every ε, that's the collapse; α(ε)=2.03+0.26·lnε captures the eps-varying min_samples occupancy effect). Right: each cluster scored through the null → its z-equivalent. A heavy-tailed statistic, once calibrated, piles into a clean standard-normal bell (the probability-integral transform).

Static demo (pure JS, no server). Domain: N=10000, radius=100 (so λ₀=1/π), min_samples=min_cluster=10, no min_area. Theory & detector: docs/analytic_findings.md.  Move the ε slider: raw R shifts dramatically, but R·εα(ε) keeps fitting the same master (<0.5% residual spread). α(ε)=2.03+0.26·lnε captures the min_samples=10 occupancy effect on effective neighbourhood area.
